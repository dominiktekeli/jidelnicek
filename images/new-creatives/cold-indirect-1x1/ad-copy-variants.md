# 6x Textace pro Cold Indirect 1:1 (Meta Ads)

Všechny texty jsou v Indirect stylu podle tutorialu:
- Vysoká zvědavost
- Organický look (vypadá jako užitečný obsah)
- Insight + "než..." / "většina maminek..."
- Žádný hard sell, copy dělá práci
- Přesný app UI text z tvého screenshotu
- Cílovka: maminky 30-45+

**Doporučené CTA pro tyto indirect:** Další informace / Zjistit cenu / Získat nabídku
