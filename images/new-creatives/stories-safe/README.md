# Klid v kuchyni - Stories Safe Zone Creatives (9:16)

Všechny tyto kreativy jsou **připravené pro Instagram Stories/Reels ads** s dodrženými safe zones:

**Safe Zones (Meta/IG Stories):**
- Top 20% clear (pro username, views, čas)
- Bottom 18-20% clear (pro swipe up, navigaci, CTA tlačítka)
- Klíčové prvky (app UI, tváře, cena, text) v centrální safe zóně (střed 60%)
- Text čitelný, vysoký kontrast, bez přetékání

**Přesný app UI** podle tvého screenshotu (žádné chyby):
- "Ahoj, máš to pod kontrolou"
- "Klid v kuchyni"
- "4 týdny jídla + 5 snídaní zdarma · nákup · opakuj kdykoliv · tipy"
- "Který týden právě jedeš?"
- TÝDEN 1 Oblíbené u dětí (kuřecí stehno)
- TÝDEN 2 Zdravě a rychle (salát)
- TÝDEN 3 Šetříme rozpočet (peníze)
- TÝDEN 4 Pohodový víkend (slunce)
- BONUS Snídaně zdarma (žlutý)
- Dolní navigace: Po (zvýrazněno), Út, St, Čt, Pá, So
- Spodní bar: Co vaříme (selected), Nákup, Tip

Všechny kombinují **reálné fotky** (maminky, rodina) + **grafika** (přesný app UI z screenshotu) + clean modern design.

Použij v Meta Ads Manager pro Stories ads. Přidej UTM parametry.

Safe zones + přesný UI = žádné chyby, dobrý delivery.
