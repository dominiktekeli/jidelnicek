# Klid v kuchyni – New Creatives (podle tutorialu Direct vs Indirect)

Všechny tyto reklamy jsou **nové**, vytvořené striktně podle systému z tutorialu:

- **Indirect** = pro cold traffic (Advantage+ Broad). Vypadají jako organický obsah, vysoká zvědavost, insight, copy prodává.
- **Direct** = pro retargeting. Jasný produkt, cena, benefit, silné CTA.

Používají se existující fotky z `../creatives/`, ale s úplně novým copy (žádné staré hooky).

## Struktura složky
- indirect-01.md až indirect-04.md
- direct-01.md až direct-03.md
- Každý soubor obsahuje kompletní specifikaci pro Meta Ads:
  - Kterou kreativu použít
  - Primary Text (plný)
  - Headline
  - Description
  - CTA
  - Doporučený UTM
  - Poznámka proč je Indirect/Direct

## Doporučené použití v ad setech
- Cold kampaň (Advantage+ Broad) → Indirect ads (většina rozpočtu)
- Retargeting kampaň → Direct ads

Všechny destination URL směřují na https://klidvkuchyni.cz s UTM.

Nové verze s reálnými fotkami a grafikou pro lepší přitažlivost pro maminky 30-45+:

- indirect-*-photo-9x16.jpg : Emoční, před/po, insight style s fotkami (stressed-calm, before-after, app, family)

Tyto kombinují reálné fotografie (maminky, rodina, jídlo, app) s čistou moderní grafikou (texty, badge s cenou, ikony, zelené akcenty). Cílem je zastavit scroll, vzbudit emoce (úleva, klid, "to bych taky chtěla") a vypadat jako hodnotný obsah, ne agresivní reklama.

Všechny jsou vertical 9:16 (Stories/Reels/Feed). Pro 1:1 verze řekni.

Používej společně s .md soubory pro copy.

## Meta Ads Safe Zones & Best Practices (DŮLEŽITÉ!)

Všechny *-safe-9x16.jpg kreativy jsou optimalizované pro Meta:

- **Minimal text on image** (short hook + big price badge + logo only). Dlouhý text patří do **Primary Text / Headline** polí v Ads Manageru (viz .md soubory).
- **Safe margins**: minimálně 12% volného prostoru od všech okrajů.
- **9:16 vertical (Stories/Reels)**: Klíčové prvky (tváře, cena, hlavní hook) jsou v centrální safe zóně. Vyhnuto top 15% (username) a bottom 18% (navigace).
- Text je velký, čitelný, s kontrastem, žádné přetékání.
- Foto je hlavní (hero), grafika je čistá a podporující (zelené akcenty, badge).

Tyto by měly projít Meta text overlay checkerem a mít lepší delivery.

Pro 1:1 (feed) verze řekni, vygeneruji je se stejnými pravidly.
